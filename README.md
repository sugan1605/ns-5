# NS-5 | AI Companion & Cloud Platform

> A friendly AI companion with personality, memory and a cloud-native foundation.

## Overview

NS-5 is a personal AI companion designed to combine an expressive user interface with intelligent backend capabilities.

The project explores how modern application development and cloud engineering can come together to build an interactive, context-aware digital companion.

NS-5 is being developed as a hands-on engineering project, with an emphasis on clean architecture, automation, infrastructure as code and operational reliability.

## Project Goals

- Build an interactive AI companion with a distinctive personality.
- Develop a responsive frontend using React and TypeScript.
- Build a Python backend using FastAPI.
- Implement persistent memory for notes and reminders.
- Provision cloud infrastructure using AWS and Terraform.
- Containerise application services using Docker.
- Practise Kubernetes orchestration in a local environment.
- Automate testing and deployment with GitHub Actions.
- Introduce monitoring, logging and observability.
